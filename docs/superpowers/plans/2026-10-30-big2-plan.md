# Big 2 Plan

Two projects that share one rulebook:

1. **Model:** a strong bot under the house rules, small enough to run in the browser. Design: `docs/superpowers/specs/2026-10-30-model-upgrade-design.md`.
2. **Web app:** built from scratch in this repo, running the trained bot in the browser.

This repo replaces the original `big2` repo. Only the engine, the bots used as test opponents, the self-play trainer, the evaluation scripts and the chosen model were brought over.

## Findings that shaped the plan

| Finding | Evidence |
|---|---|
| The original repo's best model was no better than the bots | 25.8% vs 3 greedy (400 games), 30.6% vs 3 rule-based (160 games), 21.7% vs 3 Smart (2,000 games). 25% is break-even. |
| Old training was throttled by the rule-based bot | 6.7 s per game vs 16 ms for self-play; it brute-forces every possible 5-card combination of unseen cards. |
| A GPU does not help at this size | On the M3: same training step speed, 16x slower at scoring moves for a 0.25M-parameter model. A GPU only pays off around 3M+ parameters. |
| Cloud CPUs were slower than the Mac | A Kaggle CPU session (4 vCPUs, Xeon 2.2GHz) ran 86 games/s with 2 actors, about a quarter of the Mac. |
| Smart (Patwa 2026) is the strongest available test opponent | 31.3% as 1 Smart vs 3 greedy; greedy gets 19.2% as 1 vs 3 Smart (2,000 games each). Charlesworth 2018 uses different rules, so it cannot be used. |
| Four of a kind was broken in the original engine | Always detected as invalid: playable on top of straights, flushes and full houses, and then unbeatable. Fixed. |

## Decisions

- **House straight order:** 3-4-5-6-7 < ... < 10-J-Q-K-A < J-Q-K-A-2 < 2-3-4-5-6 < A-2-3-4-5. Same run: suit of the highest card (the 2 when present). Straight flushes use the same order. Q-K-A-2-3 and K-A-2-3-4 are not straights.
- **Training:** Deep Monte Carlo self-play only. Bots are test opponents only.
- **Evaluation:** 2,000 games per matchup with 95% margins, against Smart and the current best model. A new checkpoint replaces the best only if it wins head-to-head.
- **Model size:** at or below about 1M parameters (currently 716K) so it runs in TypeScript.
- **Hardware:** CPU on the Mac. JAX is out of scope.

### Running and monitoring

```bash
python3 train_selfplay.py --hours 8          # resumes from checkpoints/selfplay/latest.pt
tail -f checkpoints/selfplay/train.log       # throughput and loss
pkill -INT -f train_selfplay.py              # stop early with a final save
python3 benchmark.py <checkpoint> --vs smart best
python3 head_to_head.py models/selfplay_v1.pt <checkpoint>
python3 -m pytest tests/
```
